      Ajustes de Sincronización en Tiempo Real

      Conecta el dashboard con tu hoja de cálculo "SERVICIO" para que los gráficos y tablas se actualicen automáticamente.

      Con la carpeta REPORTES_ARG pública y esta clave, el dashboard busca el ID del PDF de cada servicio nuevo y lo abre directo. Sin clave, usa el índice precargado y, si no está, una búsqueda en Drive.

      ¿Cómo sincronizar?

      Para que el Dashboard funcione de manera automatizada desde una web externa, tu Google Sheet debe ser accesible sin credenciales privadas. Sigue estos sencillos pasos:

      1. Abre tu archivo SERVICIO en Google Sheets (debe contener las pestañas EQUIPOS y SERVICIO).
      2. Presiona el botón Compartir (arriba a la derecha).
      3. En el apartado Acceso general, selecciona "Cualquier persona con el enlace puede ver".
      4. Pega aquí el enlace del archivo y verifica que los nombres de pestaña coincidan con los configurados arriba. El dashboard leerá ambas pestañas automáticamente.
      5. Nota: el inventario base ya viene precargado desde el CSV del proyecto; desde Google Sheets solo se traen las actualizaciones más recientes. La configuración y los filtros quedan guardados en este navegador.
